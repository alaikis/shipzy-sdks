# SDK Examples

This directory contains example code demonstrating how to use the Zymeup SDK in various languages.

## Go

```bash
cd go
go run main.go
```

## Node.js

```bash
cd node
npm install
node demo.js
```

## Usage

Before running examples, set your API key:

```bash
# Go
export ZYMEUP_API_KEY=your-api-key

# Node
export ZYMEUP_API_TOKEN=your-api-key
```
